# Sales Call Patterns

Synthesized intelligence from discovery calls — recurring objections, surprise signals, what's landing, what isn't. Fed monthly by Sybil call analysis.

This doc is NOT updated after individual calls. It's updated when a pattern appears across 3+ calls. The Sybil monthly batch surfaces those patterns.

---

## How This Gets Updated

1. Sybil runs call analysis monthly on all discovery calls from the past 30 days
2. Output PDF gets reviewed
3. If a pattern appears 3+ times → update the relevant section below
4. If the pattern suggests a positioning or ICP shift → also update Messaging and Positioning or ICP and Qualification docs

## Sybil Prompt (Run Monthly)

Paste this into Sybil to run on all discovery calls from the past 30 days:

---

*Analyze all discovery calls from the past 30 days and extract the following in structured format:*

*1. **Company profiles** — stage, headcount, current relocation setup, NYC hiring volume across calls*<br>*2. **Pain signals** — what problems did prospects describe, in their exact words where possible*<br>*3. **Objections raised** — what pushback came up and how it was handled*<br>*4. **What landed** — which framing, stats, or stories got a visible reaction across multiple calls*<br>*5. **What didn't land** — anything that got flat or confused responses across multiple calls*<br>*6. **ICP fit patterns** — do these companies match, stretch, or contradict current ICP criteria*<br>*7. **Suggested updates** — if any pattern (appearing 3+ times) should update Sales Intelligence docs, flag it with the suggested edit and which doc it belongs in*
